Implement the Rotary Position Embedding (RoPE) attention kernel used in ESM-2, the 650M-parameter protein language model from Meta AI.

Unlike vanilla multi-head attention, ESM-2 encodes sequence position by rotating the query and key vectors before computing attention scores. This lets the model learn relative positional information without a fixed additive embedding table.

Background: what RoPE does

For a head dimension of size \(d_k\), positions are encoded using \(d_k / 2\) frequency pairs. Each pair of values \((x_{2i}, x_{2i+1})\) at token position \(m\) is rotated by angle \(\theta_i = m / 10000^{2i / d_k}\):

\[ \text{RoPE}(x, m)_{2i} = x_{2i} \cos(m\,\theta_i) - x_{2i+1} \sin(m\,\theta_i) \] \[ \text{RoPE}(x, m)_{2i+1} = x_{2i} \sin(m\,\theta_i) + x_{2i+1} \cos(m\,\theta_i) \]

Apply RoPE independently to \(Q\) and \(K\), then compute standard scaled dot-product attention, then concatenate all heads into the output:

\[ \text{head}_i = \text{softmax}\!\left(\frac{\text{RoPE}(Q_i, m)\;\text{RoPE}(K_i, m)^T}{\sqrt{d_k}}\right) V_i \] \[ \text{RoPEAttn}(Q, K, V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) \in \mathbb{R}^{N \times d_{\text{model}}} \]

Implementation Requirements

  • Use only native features (external libraries are not permitted)
  • The solve function signature must remain unchanged
  • The final result must be stored in the output array
  • positions is an integer array of length \(N\) giving the token position index for each row (0-indexed, supports non-contiguous sequences)

Example 1:

Input: \[ N = 2,\quad d_{\text{model}} = 4,\quad h = 2,\quad \text{positions} = [0, 1] \] \[ Q = K = V = \begin{bmatrix} 1 & 0 & 0 & 1 \\ 0 & 1 & 1 & 0 \end{bmatrix} \]

Expected output: same as RoPE-attended result (see reference implementation). Position 0 has no rotation (\(\cos 0 = 1, \sin 0 = 0\)), so head outputs at position 0 match standard MHA. Position 1 rotates by \(\theta_0 = 1/10000^0 = 1\) rad and \(\theta_1 = 1/10000^{0.5} \approx 0.01\) rad.

Example 2 (ESM-2 config):

\(N = 142\) (SNCA protein, L=140 + BOS + EOS), \(d_{\text{model}} = 1280\), \(h = 20\), \(d_k = 64\). Positions \([0, 1, \ldots, 141]\). This is the exact configuration run 140 times per masked-marginal variant scoring pass.

Constraints

  • 1 ≤ N ≤ 4096
  • d_model ∈ {128, 256, 512, 640, 1024, 1280}
  • 1 ≤ h ≤ d_model / 64, d_model % h == 0
  • 0 ≤ positions[i] < 4096
  • Performance is measured with N = 142, d_model = 1280, h = 20 (ESM-2 650M config)
